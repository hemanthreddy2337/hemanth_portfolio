BONAGIRI HEMANTH REDDY — PORTFOLIO

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder.
3. Open index.html in Chrome or another browser.

PUBLISH ONLINE WITH GITHUB PAGES
1. Create a GitHub repository named hemanthreddy2337.github.io.
2. Upload index.html and the complete assets folder (keep the folder structure).
3. In repository Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.
4. After GitHub Pages finishes deploying, your website will be available at https://hemanthreddy2337.github.io/

Keep assets beside index.html so certificate images load correctly.
